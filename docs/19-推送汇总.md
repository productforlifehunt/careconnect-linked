# 19. 推送汇总（Notification Inventory）

最后更新：2026-09-08（收件箱聚合之后）

## 全局规则

- **唯一收件表面**：`/inbox`。独立的 `/messages`、`/notifications` 路由已删除，不做转发。
  所有入口直接进 `/inbox?tab=all | notifications | messages`。
- **筛选**：收件箱同一行有三个标签（全部 / 通知 / 消息）+ 右侧读写筛选（全部 / 未读 / 已读），三个标签共用。
- **统一出口**：所有推送都走 `src/features/notifications/notify-events.ts` 的 `notifyUsers()`
  → 写入 WordPress CCT 185（通知表），关系由 JetEngine Relation 处理。
- **失败不阻塞**：推送写入失败不会让主业务写入失败（best-effort）。
- **自己不收自己**：`notifyUsers()` 会剔除当前操作者并去重。
- **命名统一**：原 “共享任务 / shared task” 一律称 **任务（tasks）**。
