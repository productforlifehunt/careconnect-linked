# AI 对话与分析汇总

## 共用规则

- 品牌人格和名字只在 `supabase/functions/_shared/ai-prompts.ts` 定义；前端按 `challenged`、`carecnc`、`notchsafety` 选取当前品牌，系统提示保持精简。
- 所有对话经 `src/lib/ai.ts` 调用 `supabase/functions/ai/index.ts`，文本模型为 `openai/gpt-5-nano`，`reasoning_effort` 为 `none`。
- 数据模型、查询权限、App 差异、会话记录和写入技能只在 `src/lib/ai-dynamic-knowledge.ts`；读取按当前问题触发，聊天记录使用现有 CCT 121 / CCT 126 和 REL 137 / REL 138。
- App 操作指南、群组指南、护理知识和每轮对话规则只在 `src/lib/ai-static-knowledge.ts`；`assistant.conversation` 每轮加载，其他条目按关键词或技能名加载。
- 页面只声明上下文范围、静态技能和写入技能名，不复制数据库字段或权限判断。共享信息卡只把卡片上已显示的内容交给 AI，不追加读取私人照护记录。

## 入口

| 功能 | 页面 / 组件 | 按需动态读取 | 静态技能 / 写入 |
|---|---|---|---|
| AI 智能简报 | `/dashboard` → `AISmartBriefing.tsx` | `resolveBriefingFacts()`、`resolveTaskFacts()`；按需读取 CCT 187 预约、未读会话和 CCT 185 通知；仅在 CCT 258 允许位置分享时读取 CCT 213 最新位置 | `buildBriefingRequest()`；无写入 |
| 通用 AI 助手 | 悬浮球 → `AICompanionChatDialog.tsx` → `AICompanionChat.tsx` | `resolveAssistantContext()`；每轮身份提示、用户资料、群组和按需个人记录；会话读写走 `assistant-conversations` | `assistant.conversation`；按需加载 `app-basics`、`care-group`、`care-tips`；用户明确要求时执行 `save-care-tip` |
| App 使用帮助 | `MobileBottomBar.tsx` 打开同一 `AICompanionChat` | 与通用助手相同 | 快捷问题从 `appGuideEntries()` 直接显示静态答案；其他问题可继续交给同一 AI 助手 |
| 群组帮助 | `/care-circle` → `GroupHelpTab.tsx` | `resolveGroupAccess()`、`resolveGroupFacts()` | `care-group`、`app-basics`；只读当前群组 |
| AI 探望签到 | `CheckInCard.tsx` → `openWriteAssistant({skill:"record-check-in"})` | `resolveCheckInFacts()` | `record-check-in`，完成后刷新签到记录 |
| AI 用药记录 | `MedicineCard.tsx` → `openWriteAssistant({skill:"record-medicine-dose"})` | `resolveMedicineFacts()` | `record-medicine-dose`，完成后刷新用药记录 |
| 信息卡助手 | 私有卡片 `InformationCardCard.tsx`、共享卡片 `SharedInformationCard.tsx` → `SheetAIPanel` → 同一 `AICompanionChat` | 私有卡片按权限和问题读取照护计划、提示、笔记、用药或位置；公开卡片不读取额外私人资料 | `care-tips`；不写入 |

## 写入技能

`record-medicine-dose`、`record-check-in` 和 `save-care-tip` 的结构、允许状态、权限检查、App 适配和真实写入均由 `src/lib/ai-dynamic-knowledge.ts` 的技能名分派。常规聊天不写入；AI 输出成功状态后才执行对应写入。

护理小贴士沿用现有 `T.careTip` / `R.caredOneCareTips` 数据结构。当前字典中 CCT 199 的 a58 是群组加入码，不是护理小贴士字段；不要将小贴士写入该字段。

## Edge task 状态

`supabase/functions/ai/index.ts` 按 `task` 路由；逗号、`+` 和 `|` 可分隔多个 task。源码已实现 `chat-chat`、`vision-chat`、`chat-voice`、`voice-chat` 和 `chat-translate`；通用助手的图片先在浏览器压缩，再随文本发给 `vision-chat`，图片不写入 CCT121 / CCT126，会话仅保存文字问题。当前连接的线上 Edge Function 仍返回 `501 task not implemented yet: vision-chat`，部署更新后图片识别才会在线可用。`chat-vision`（文字生成图片）及其他视觉输出组合仍未实现。
