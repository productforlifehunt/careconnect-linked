# 21 · AI 功能汇总（真实代码状态，2026-09-08）

统一规则：
- system prompt：`supabase/functions/_shared/ai-prompts.ts`（只有人格/语气/禁忌 + 品牌名）
- 动态查询 + 权限 + 所有写入：`src/lib/ai-dynamic-knowledge.ts`（唯一 skill 文件，读写同条）
- 静态知识（App/群组指南、护理小贴士）：`src/lib/ai-static-knowledge.ts`（按小条按需检索）
- 对话发送：`supabase/functions/ai/index.ts`，`openai/gpt-5-nano`，`reasoning_effort: "none"`
- `src/lib/ai-auto-fill-form.ts` 已删除，写入登记合并进 `ai-dynamic-knowledge.ts`
- 通用行为规则（护理者/被护理者身份可随对话切换、把资料当自己知道的事自然说、不编造、关键缺失让联系家属）写在 system prompt，几行、每次都发
- 情景技巧（怀疑被偷、想回家、陪聊讲故事、坐不住）按关键词命中才从 `ai-static-knowledge.ts` 取一小条
- 当前用户身份作为**事实**由 `resolveViewerFacts()` 提供（仅起始假设）
