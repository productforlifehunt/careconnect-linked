# 六套品牌界面逐项统一

## 目标
确保三个品牌在英文与中文环境中完全隔离，不在任何可见位置混入另一语言、旧名称或旧标志。

| 站点 | 英文 | 中文 | 首页图片 |
|---|---|---|---|
| ChallengeD | ChallengeD + 英文标志 | 忆畅 + 中文标志 | 英文 `hero-image.jpg`；中文 `hero-image-cn.jpg` |
| CareCNC | CareCNC + 英文标志 | 护畅 + 中文标志 | 英文 `hero-image.jpg`；中文 `hero-image-carecnc.jpg` |
| NotchSafety | Notch Safety + 英文标志 | 诺驰安全 + 中文标志 | 保留当前专属图片 |

## 实施
1. 建立唯一的语言化品牌资料来源，统一输出显示名称、标志、浏览器标题、说明和各语言图标；页面和弹窗不再各自硬写品牌名。
2. 修正所有共用与专属界面：页首、页尾、登录、注册、引导、账户页、AI 弹窗、菜单、分享页、错误页以及 NotchSafety 专属页面。
3. 同步浏览器标签页标题、网页说明、分享预览标题与说明、favicon 和移动设备图标；切换语言和站点时立即更新。
4. 清除或隔离仍展示旧候选名称/旧标志的公开测试页面，避免从可访问网址看到错误品牌。
5. 保持首页正文布局与业务功能不变，只修品牌、语言和指定首页图片。

## 验证
- 静态扫描全部运行时代码，逐条检查六套界面中是否残留错误品牌名或旧标志。
- 使用浏览器逐站、逐语言打开每个适用的公开页面和弹窗，记录名称、标志、标题、图标与图片结果。
- 使用现有指定测试账号检查每个适用的登录后页面和弹窗；不修改密码或用户资料。
- 分别在桌面与手机宽度检查共享页首、登录页、主要弹窗和首页。
- 最后检查构建、运行错误、控制台和失败请求；按实际通过数量报告，不以抽样代替全量。

## 声音克隆存储（本轮只记录准确方案，不接入供应商）
- 私有文件存储保存获得授权的原始 MP3/WAV/M4A 参考录音。
- 数据记录保存文件地址、供应商、供应商返回的短文本 `voice_id`、授权信息和状态。
- 不把音频塞进 textarea，也不假设存在可下载、可跨供应商使用的 JSON 声纹文件。
